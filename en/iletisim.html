Quick fault report via WhatsApp

Choose your fault and WhatsApp opens with a ready message.

The fault you choose is added to the end of the message. You can add photos and your location in WhatsApp. For a more detailed request, use the service request cards.

  • 1Loss of hydraulic power, slow operation or main pump leak — write on WhatsApp (new tab)
  • 2Transmission / torque converter fault, machine will not drive — write on WhatsApp (new tab)
  • 3Low engine power, black/white smoke or turbo fault — write on WhatsApp (new tab)
  • 4Track travel motor / final drive fault or swing problem — write on WhatsApp (new tab)
  • 5Hydraulic pump whining, humming or noise (cavitation/suction) — write on WhatsApp (new tab)
  • 6Other (I want to describe the fault myself) — write on WhatsApp (new tab)
